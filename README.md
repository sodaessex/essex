# My Project

This repository contains the source code and experimental results for my project.

## Overview

项目介绍：基于Visual Studio与EasyX开发的2D游戏项目，围绕角色移动、攻击、敌人、子弹、地图碰撞及地图显示等功能进行实现与调试。
实现效果：角色移动与方向控制、攻击及动画等功能；实现地图碰撞检测、摄像机跟随和小地图等功能，并针对图片加载、坐标转换、碰撞区域判断等问题进行调试完成游戏核心交互功能及地图相关功能，实现角色在可行走区域内移动，并支持地图跟随和小地图显示。
